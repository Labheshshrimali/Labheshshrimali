## 🚀 Featured Projects

### 🔎 Codebase Assistant

A hybrid RAG system that lets you ask questions about GitHub repositories and returns answers with references to the relevant source code.

**Python · FastAPI · React · Qdrant · BM25 · Tree-sitter · Docker**

- AST-based code chunking using Tree-sitter
- Hybrid retrieval using vector search, BM25 and call-graph retrieval
- Cross-encoder reranking
- REST APIs for repository ingestion and querying
- Evaluated on 25 questions using Precision@6 and Recall@6
- Deployed on Hugging Face Spaces

[View Repository](https://github.com/Labheshshrimali/codebase-assistant)
